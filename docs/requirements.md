# 요구사항 정의서

도메인은 원피스 애니메이션 시청 계획이다. 캐릭터 이름·별칭을 입력하고 첫 등장 회차와 시청 시간을 조회한다. 예를 들어 “나미 첫 등장 편을 토요일 18:00~18:10 또는 일요일 19:00~19:30에 보고 싶어”에서 러닝타임이 25분이면 토요일은 제외하고 일요일을 제안한다. 사용자가 확정한 계획에서 회차, 시작·종료 시각, 생성 일시를 SQLite에 저장한다.

## 비기능 및 범위

| 번호 | 적용 기준 |
|---|---|
| NF3001·NF3002 | 모델 키는 환경 설정으로 관리, 예외는 사용자용 오류로 변환, 배포본에는 예제 설정 포함 |
| NF3003·NF3004 | 도구 실패 사유를 기록하고 답변 반환, 재계획 최대 3회 |
| NF3005 | 대표 요청별 처리 시간을 기록하고 모델과 공개 API를 연결한 실제 환경에서 별도 확인 |
| NF3006 | Agent·Tool·저장·웹 API·화면 모듈 분리 |
| NF3007 | 외부 API의 출처와 확인된 제한 기록. 상세 확인 범위는 소스 README 참고 |
| F3020~F3023 | 심화 기능은 이번 제출 범위에서 제외 |

## 기획 검증과 변경

One Piece API의 이름과 ID, 회차 자료의 통산 번호·방영일, TVmaze의 회차·러닝타임을 연결했다. 실제 공개 API 재확인 결과는 [호출 출력](../evidence/live-api.txt)에 기록했다. 제목이 다른 번역으로 돌아오거나 같은 날 여러 화가 방영되는 경우가 있어 정규 회차의 순서와 제목·방영일을 대조한다. 한글 이름은 정식 표기·등록 별칭을 우선하고 공개 이름의 일본어·로마자 독음을 보완해 색인에 포함했다. 마감 시각만 있는 요청은 일정 저장과 분리해 마지막 시작 가능 시각을 계산한다.
