# 검증 결과

배포 소스로 자동 테스트 11개를 실행했고 모두 통과했다. 로빈·루피·조로·나미·상디·샹크스는 공개 API에서 검색부터 회차·시청 시간까지 재확인했다. 아래 5건은 사용자 문장에 대응하는 분석 결과와 외부 응답을 고정한 상태로 실행했다. 단계 실행, 일정 비교, 재계획, 이벤트 발행과 SQLite 저장에는 제품 코드를 사용했다. 기록된 시간은 이 검증 경로의 처리 시간이다.

| 사례 | 기대 동작 | 실제 결과 | 로그 |
|---|---|---|---|
| 즉시 충족 | 토요일 18:00~19:00에 25분 시청 | 18:00~18:25 제안, 재계획 0회 | [s1](../evidence/s1-trace.json) |
| 재계획 | 토요일 10분 구간 제외 후 일요일 선택 | 부족 사유와 일요일 19:00~19:25, 재계획 1회 | [s2](../evidence/s2-trace.json) |
| 상한 | 10분 구간만 5개 제공 | 재계획 3회 후 상한 안내 | [s3](../evidence/s3-trace.json) |
| Tool 실패 | 시청 시간 누락 시 확인된 정보만 반환 | 1화와 NO_RUNTIME 안내 | [s4](../evidence/s4-trace.json) |
| Tool 불필요 | 인사 입력 시 도구 호출 없음 | 지정한 인사 응답 반환, 도구 호출 0회 | [s5](../evidence/s5-trace.json) |

검증 조건에서 다섯 사례는 기대와 일치했다. [시나리오 결과 JSON](../evidence/scenario-results.json)에 측정 시간과 예상·실제 차이를 기록했다. 모델 호출과 네트워크가 포함된 전체 응답 시간은 사용자 환경에서 재측정한다.

## 제출 전 남은 확인

- 실제 모델 키·LangGraph를 연결해 조건 추출, 인사, 마감 역산, 후속 요청의 조건 유지, 판단 로그를 확인한다.
- 브라우저 구동이 제한된 환경에서 검증했다. 실제 브라우저에서 처리 중 상태, 계획 수정·삭제 즉시 반영, 오류 안내를 확인하고 화면을 캡처한다. 화면이 필요한 체크리스트 행에는 미확인 사유를 기입했다.
- 출처별 공개 이용 조건과 호출 한도를 확인한다. 확인한 범위는 소스 README에 있다.
- Google Calendar 및 다른 심화 기능은 이번 제출 범위에서 제외했다.
